# MiNegocioGO
**Conecta. Vende. Crece. ¡GO!**

## Descripción
MiNegocioGO es una aplicación orientada a pequeños comerciantes. El proyecto busca facilitar la gestión de productos e inventario, el registro de ventas y, posteriormente, ofrecer un canal de venta online con carrito, pedidos a domicilio y forma de pago.
