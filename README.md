**Conecta. Vende. Crece. ¡GO!**

## ¿Qué es MiNegocioGO?

MiNegocioGO es una aplicación pensada para apoyar a los pequeños comerciantes en la organización de su negocio.

La aplicación permitirá registrar y consultar productos, controlar las existencias, registrar ventas y ofrecer productos para venta online. También permitirá que los clientes agreguen productos al carrito, realicen pedidos a domicilio y seleccionen una forma de pago.

## Épicas

### Gestión de inventario
Registro, actualización y control de productos y existencias.

### Gestión de ventas
Registro y consulta de las ventas realizadas.

### Ventas online y pedidos
Publicación de productos, carrito de compra, pedidos a domicilio, forma de pago y consulta del estado del pedido.
